# Vehicle models (free, credited)

Upload `.glb` vehicle models here, named after the game's vehicle type (for example `alto.glb`,
`padmini.glb`, `ambassador.glb`; the list is in `docs/art-requests.md`). Only CC0 or CC BY
(Attribution) licences. Add one credit line per file to `../CREDITS.md`: file — title by author
(link) — licence — date. The build makes a light copy of each upload; the game drops the
model's own textures (no real logos or number plates) and paints it with its own materials.
