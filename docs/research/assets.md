# GTB — free asset shortlist

Machine-readable version: [`assets.json`](assets.json) (same entries, same ids). Researched 2026-11-13.

**Rules applied:** only CC0-1.0, CC-BY-4.0 or OFL-1.1. No NC/ND/editorial/store licences. Textures 2K max (1K where the 2K zip is over 25 MB). All non-Sketchfab download links were checked (HTTP 200) on 2026-11-13.

**Summary:** 126 assets — 38 texture, 8 hdri, 9 tree, 17 vehicle, 2 character, 2 animation, 17 prop, 21 sound, 12 font. Login needed: 17 (all Sketchfab models; each has a no-login CC0 fallback from Kenney/Quaternius).

**Notes for the build pipeline**

- Poly Haven textures: `download_url` is the colour map; `extra_urls` holds the normal (OpenGL) and roughness maps. Poly Haven glTF models reference a `.bin` and textures next to the `.gltf` — fetch the full list from `https://api.polyhaven.com/files/<id>` (key `gltf → 1k → gltf → include`).
- ambientCG / OpenGameArt links are zips: keep only Color, NormalGL, Roughness (textures) or the glTF/FBX you need (models). Convert FBX → glTF with Blender CLI or `FBX2glTF`, then compress (meshopt/Draco + KTX2).
- Freesound `download_url` is the public HQ OGG preview (no login, same licence). Original WAVs need a free Freesound account.
- Sketchfab needs a free account or an API token (`GET /v3/models/{uid}/download`). Store the token as a GitHub secret if used.
- Remove real brand badges/logos from vehicle models (Tata, Ashok Leyland, Hindustan etc.) and rename in game.

## Not found / gaps

- **Premier Padmini** (classic kaali-peeli): no free CC0/CC-BY model found. Use the Hindustan Ambassador (shortened) or model a simple Padmini from a Kenney sedan.
- **Mumbai local EMU coach**: only a low-quality CC-BY model (0 likes). Recommend building procedurally: 20.6 m box, rounded roof, window-strip + livery texture.
- **BEST e-double-decker, BEST single-deck with Indian body**: no faithful free model; repaint the city bus / double-decker bases.
- **Gulmohar, peepal, rain tree**: no specific free models. Tint generic broadleaf trees (Quaternius) — gulmohar canopy orange-red #E2492F in Apr–Jun.
- **Dabbawala bicycle with tiffin crates, chai stall, police barricade (MUMBAI POLICE yellow-black), police booth (chowky), satellite dish (DTH), billboard frame**: no good free matches — simple shapes, best modelled procedurally (all are boxes/cylinders + a texture).
- **Blue tarpaulin**: no dedicated CC0 tarp texture — use ambientCG Plastic015A + wrinkle normal.
- **Kerb stone with black-yellow paint**: no texture — use concrete_pavement + a shader stripe (alternating 0.6 m black #1A1A1A / yellow #F2C200).
- **Vendor calls from Mumbai**: only a Kolkata hawker recording (CC-BY). Record your own or use generic Indian market ambience.
- **Monsoon-specific rain**: generic heavy-rain CC0 recordings used.
