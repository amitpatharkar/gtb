# Mumbai vehicles, free assets and physics engines (2026-11-13)

**Legend:** **≈** means approximate, **(?)** means unverified. Sizes are in millimetres: length × width × height / wheelbase. Indian makers rarely publish track width; use **track ≈ width − 150 to 220 mm** (estimate).

### Taxis and auto-rickshaws
- **Premier Padmini → Premiere Padmavati** (classic kaali-peeli):
  - Retired 30 October 2023, so use it as a rare vintage spawn.
  - Size 3730×1470×1430 / 2340. Track ≈1230 front, 1215 rear (from the Fiat 1100D; unverified).
- **Kaali-peeli taxis today:**
  - About 45,000 in the Mumbai region (one 2026 report says 44,825).
  - Mostly WagonR, Santro/i10 and Alto/Celerio, with some Dzire, Indica and electric cars.
  - Black lower body, yellow upper body.
- **Cool Cab:** blue body with a silver band, air-conditioned, runs on CNG. The current models are unknown, so use Ertiga or Dzire shapes.
- **Auto-rickshaws: Bajaj RE → Bajaaj Re-Kshaw; TVS King → TVZ Raja.**
  - Sizes: RE ≈2650×1300×1710 / 2000; King ≈2647×1329×1740 / 1990.
  - Shape: single front wheel, handlebar, canvas hood with roll-down side curtains.
  - **Mumbai autos are black and yellow.** Green and yellow is Delhi's CNG livery.
  - Autos are banned in the island city, so they only belong in the suburbs.

## Part 2: Free assets

**How to handle packs with no fixed download link (for example itch.io):**
1. Download the pack once by hand.
2. Upload it to a **GitHub Release** of the repository. Releases allow files up to 2 GiB, are public and need no login.
3. The GitHub Action then downloads it like any other web address.

This also gets around Git's 100 MB file limit.

### b) Indian vehicles
- **Sketchfab:**
  - Downloads need a logged-in user. A personal **API token** stored as a GitHub secret means *you* download your own copies, which looks allowed under the [API terms](https://sketchfab.com/developers/terms) (unverified).
  - `build-assets.mjs` currently **skips** all 20 login-only entries. Adding a `SKETCHFAB_API_TOKEN` secret would unlock them.
  - **Risk:** Epic is moving Sketchfab into its Fab store, and free downloads may end later. Save the converted models and their credits on the `assets` branch now; CC-BY allows this.
- **New finds:**
  - a ["mini truck"](https://sketchfab.com/3d-models/mini-truck-71e499219de548a7a1be74c237b6a2fb) tagged as a Tata Ace (CC-BY);
  - a [Royal Enfield Classic 350](https://sketchfab.com/3d-models/royal-enfield-classic-350-46f293d412d946b4860f44cc7e05613d) (licence unverified).
- **Not found:** no CC0/CC-BY Alto, WagonR, Activa, Splendor, Bolero, BEST bus or Padmini. Models from CGTrader or RenderHub are paid-store licences that forbid public redistribution.
- **Poly Pizza:** CC0/CC-BY models, but only generic low-poly cars; its API needs a free key.
- **Verdict:** keep generating vehicles in code (`fleet.js`) and rebuild each type from Part 1. Use downloaded models only for hero vehicles and as reference.

### c) Props, materials, skies and audio
**Props:**
- [Kenney City Kit Industrial](https://kenney.nl/assets/city-kit-industrial) (CC0, June 2025, on OpenGameArt with no login): tanks, pipes and chimneys for the docks and the Byculla mills.
- "Electric Pole PSX" ([itch.io](https://notsospecialgames.itch.io/electric-pole), CC0 per its page; get it through a GitHub Release). Draw the wire tangles in code.
- Keep water tanks, signboards and shutters as they are now (built in code or in the shader).

**Materials:** most needs are already covered. Add:
- Poly Haven "Red Laterite Soil Stones" (CC0; exact asset name unverified);
- TextureCan ["Leaky Dirt" decal](https://texturecan.com/details/516) (CC0 per the site) for monsoon stains under windows and AC units.

**Skies:**
- I found no Poly Haven sky photographed in India.
- Keep the "pure sky" versions, which have no foreign buildings in reflections.
- The Action can list sky images from `api.polyhaven.com/assets?t=hdris&c=skies` (no key needed) and pick pure-sky ones for dawn, dusk and night.

**Audio:**
- The 21 Freesound clips on the list already cover the basics.
- For more, use the Freesound API (free key) with the tags mumbai, india, hindi and bazaar.
- **Sonniss game-audio bundles:** no attribution needed, but files may not be shared on their own. Never put the raw files on the public branch.
- **Reject:** BBC sound effects (personal use only) and any licence that is non-commercial or share-alike.
- Hindi/Marathi crowd chatter: almost nothing free exists. Recording a few minutes on a phone is the best free source.

### d) Physics engines
Sizes are measured today from npm packages, gzip-compressed.

| Engine | Version | Download size | Vehicles | Ragdoll and props | Notes |
|---|---|---|---|---|---|
| **@dimforge/rapier3d-compat** | 0.21.0 (Sep 2026) | **1.61 MB** | raycast vehicle controller (suspension, grip, engine, brakes, steering) | joints, sleeping bodies | 0.21 **added soft bodies, which doubled its size. Version 0.19.3 = 0.81 MB.** three.js r187's Rapier helper uses 0.21.0. |
| jolt-physics | 1.1.1 | 0.86 MB | full engine and gearbox simulation, plus **motorbikes** | built-in **ragdolls**, soft bodies | memory must be freed by hand; the multithreaded build needs server headers that GitHub Pages cannot send |
| cannon-es | 0.20.0 (2022, unmaintained) | **0.07 MB** | raycast vehicle | constraints | plain JavaScript, slower, no fast-object collision checks |
| Ammo.js | stale | 0.34 MB | raycast vehicle | constraint ragdolls | old Bullet engine, awkward to use |

**Recommendation: Rapier, pinned to version 0.19.3 (≈0.8 MB).** Load it after the city appears so the first load stays light.
- Keep the current taxi handling. Traffic stays on scripted paths, moved by code instead of simulated forces.
- Make thelas, bins, cones and garbage real physics objects that sleep when still.
- "Ragdoll-lite": 8–10 capsule shapes joined together, switched on when a person is knocked down, then blended back into animation after about 2 seconds.
- **Runner-up: Jolt**, if motorbike and ragdoll realism matter more than ease of use.
